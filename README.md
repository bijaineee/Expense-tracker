# 💸 Expense Manager App

A simple expense tracker built with Streamlit and SQLite. Add, view, update and delete expenses in ₹, with a custom dashboard-style UI.

## Features
- Add expenses with category, amount and date
- View all expenses with a running total
- Update or delete an expense by ID
- Custom styling (`style.css`)

## Run locally
```bash
pip install -r requirements.txt
streamlit run expense_manager_app.py
```

## Files
- `expense_manager_app.py` – the app
- `style.css` – UI theme (must stay in the same folder as the app)
- `requirements.txt` – dependencies
